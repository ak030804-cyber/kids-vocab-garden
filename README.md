# 字樹花園 · 每日單字

小朋友每日英文單字學習 PWA。

- 每日小量學習任務
- 三種題型：聽音選字、字母積木拼字、認字
- 間隔複習（SRS，學過嘅字定時返嚟）
- 遊戲化「字樹花園」：完成任務澆水、連續天數會令棵樹長大
- 家長報告：學習天數 / 題數 / 時間 / 首次正確率 / 題型分佈
- 支援多個小朋友 profile（資料存喺裝置本機，唔會上傳）

## 使用

手機瀏覽器打開 Pages 網址，iOS Safari 用「加入主畫面」就可以當 App 用。

## 技術

純 HTML / CSS / vanilla JS，無 build step，可離線（service worker）。

## 開發

```
python3 -m http.server 8088
```
